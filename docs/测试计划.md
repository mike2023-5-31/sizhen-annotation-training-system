## 1. 测试目标与范围

### 1.1 目标

验证 Backend 在本地开发机（CPU-only）上的全部可自动化路径：

1. 各服务与工具模块的功能正确性（单元测试）；
2. 服务间全链路协作（集成测试与端到端测试）；
3. 无 CUDA 环境下的自动降级行为（CPU 降级路径）；
4. 回归基线：`92` 个用例全部通过，无失败、无错误。

### 1.2 范围（按 app 模块）

| 模块 | 文件 | 是否纳入自动化 | 说明 |
|------|------|----------------|------|
| 配置 | `app/config.py` | 是 | 通过各服务测试间接覆盖 |
| 数据库 | `app/db.py`、`app/models/orm.py` | 是 | SQLite 测试库，隔离 `DB_URL` |
| 标签体系 | `app/labels_config.py` | 是 | 锁定决策 1 的约束校验 |
| 模型工厂 | `app/models/factory.py` | 是 | ResNet18/50 四头 + 自定义模型 |
| 数据集服务 | `app/services/dataset_service.py` | 是 | CRUD 与唯一约束 |
| 导入服务 | `app/services/import_service.py` | 是 | ZIP 白名单与配对落盘 |
| XML 读写 | `app/services/xml_io.py` | 是 | 往返一致性 |
| 训练服务 | `app/services/train_service.py` | 是 | CPU 冒烟、断点续训 |
| 推理服务 | `app/services/inference_service.py` | 是 | checkpoint 加载与预测 |
| ONNX 服务 | `app/services/onnx_service.py` | 是 | 转换与精度对比 |
| API 路由 | `app/routers/*.py` | 部分 | 训练监控 API 纳入；其余经 e2e 覆盖 |
| GPU / FP16 / DataParallel | 训练引擎真实路径 | 否（本地） | 见 [GPU_SMOKE.md](./GPU_SMOKE.md)，服务器人工冒烟 |

### 1.3 不纳入本计划的内容

- GPU 服务器上的 CUDA 可见性、FP16 AMP、DataParallel 双卡显存验证：由 `docs/GPU_SMOKE.md`（T25 runbook）在服务器（`59.77.6.21:6107`，2×RTX 3090）人工执行；
- 前端（`frontend/`）测试；
- 性能与压力测试。

## 3. 测试层级与策略

| 层级 | 对应文件 | 策略 |
|------|----------|------|
| 单元测试 | `test_xml_io` `test_factory` `test_labels_config` `test_onnx` | 纯函数与模块级行为，mock 外部依赖 |
| 服务级测试 | `test_dataset_crud` `test_import` `test_train` `test_inference` `test_gpu_fallback` | 真实 SQLite + 合成数据，训练/推理走 CPU 真实执行 |

## 6. 验收标准

| 编号 | 标准 | 判定 |
|------|------|------|
| AC-1 | `pytest tests/` 全部用例通过（92/92），0 失败、0 错误 | 必须满足 |
| AC-2 | 警告数 ≤ 2，且全部为已知的 fastapi/starlette 弃用警告（非代码缺陷） | 必须满足 |
| AC-3 | `test_e2e` 通过，services 全链路无断点 | 必须满足 |
| AC-4 | `test_gpu_fallback` 通过，CPU 降级路径不崩溃 | 必须满足 |
| AC-5 | GPU/FP16/DataParallel 真实路径：服务器按 GPU_SMOKE.md 三项清单全 PASS | 冒烟项，本地不执行 |

## 7. 风险与限制

1. 本地为 torch CPU 版，GPU 真实路径未被本地自动化覆盖，需按 [GPU_SMOKE.md](./GPU_SMOKE.md) 在服务器补测；
2. ONNX 精度对比（1e-3）依赖本地 ONNX Runtime 的 CPU EP，与 GPU EP 结果可能存在微小差异，但阈值设计已留裕量；
3. 测试库为 SQLite，生产库的 SQL 方言差异（如唯一约束报错类型）不在本计划覆盖范围。
