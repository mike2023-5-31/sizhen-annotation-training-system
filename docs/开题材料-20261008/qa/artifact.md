# 表格填写约定
参照：qa/审核模板.docx、qa/选题模板.docx；哈希与完整包清单见reference_inventory.json。
审核表：原A4，四边2cm；表格原列宽、黑边、合并关系、个人信息、页码及三类意见签名区全部保留。只填第4至7行的右侧空白区域；标题居中，摘要正文宋体12pt，18pt最小行距。需保持2页双面表格。
选题报告：原A4，上下2.54cm、左右3.175cm；封面保留学校标题与楷体字段，填写姓名、专业、导师、入学时间和用户确认的报告日期。论文标题较长，填写值用14pt适配原字段。保留六项栏目和单列表格，前五行随正文扩展；正文宋体12pt，18pt最小行距；参考文献10.5pt，16pt最小行距。小组仅填已知导师姓名，其余名单和签名日期不猜填。
仅修改document.xml。所有关系、样式、主题、页眉页脚、设置与其他包部件须字节相同。允许正文填入使选题报告分页增长；不新增批准意见、不代签。
模板初始渲染：Word 16.0只读打开导出PDF，Poppler生成各2页PNG，均已检视。
