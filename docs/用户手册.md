## 1. 系统简介

本系统面向中医四诊（望舌、望面、切脉、闻声音）影像与声音数据的标注、管理、模型训练与推理部署场景。核心工作流是一条链路：

**导入 → 标注 → 导出 → 训练 → 评估 → 推理 → ONNX 转换与下载**

- 前端页面负责浏览、标注、配置与结果展示。
- 后端服务（FastAPI）负责数据读写、训练、推理与模型转换。
- 标签体系固定为 4 个并列类别：**舌、面、脉、声音**，每类子标签以 `backend/config/labels.yaml` 为准（当前为占位默认值，可自行修改后重启后端生效）。

### 1.1 启动方式

系统启动（后端 + 前端）的完整步骤见 `docs/部署文档.md`。本地开发启动后：

- 前端页面入口：`http://localhost:5173`
- 后端服务入口：`http://localhost:8000`（交互式接口文档 `http://localhost:8000/docs`）

## 3. 功能操作指南（6.1 至 6.21）

### 3.1 数据集管理（需求 6.1）

页面：`/datasets`

| 操作 | 步骤 |
| --- | --- |
| 创建数据集 | 1. 点击页面右上「新建数据集」按钮；2. 在弹窗输入数据集名称（不可为空）；3. 点「确定」。名称与已有数据集重名时系统报错（409），提示「数据集名称已存在」。 |
| 查看列表 | 打开页面即自动加载全部数据集，表格列：ID、名称、创建时间、更新时间。点「刷新」按钮可重新加载。 |
| 重命名 | 1. 在目标行点击「重命名」；2. 弹窗输入新名称；3. 点「确定」。改名即时生效并反映在表格中。 |
| 删除 | 1. 在目标行点击「删除」；2. 二次确认弹窗点「删除」。删除仅移除数据库记录，磁盘上的图片与标注文件会保留（确认弹窗中有明确提示）。 |
| 下拉选择 | 页面右上角「选择数据集」下拉框可选择当前数据集，选择结果以消息提示。其余页面（训练、推理）自带独立的数据集下拉框。 |

### 3.2 数据导入（需求 6.2）

**渠道 A：ZIP 上传导入**

入口：后端接口文档 `http://localhost:8000/docs` → 展开 `POST /api/datasets/{dataset_id}/import`

| 步骤 | 操作 |
| --- | --- |
| 1 | 在接口面板填写 `dataset_id`（目标数据集 ID）。 |
| 2 | 点「Try it out」，在 `file` 字段选择本地 ZIP 包（内含 jpg/jpeg/png/bmp/gif 图片，每张图片可配同名 XML 标注文件）。 |
| 3 | 点「Execute」执行。 |

返回汇总：`imported`（导入数）、`skipped`（跳过文件名列表，如缺 XML 的图片）、`errors`（错误明细）。损坏 ZIP 返回 400「不是有效的 ZIP 文件」；图片缺失同名 XML 时该图被跳过并列入 skipped，不影响其余图片。导入的数据同时写入内置库记录，供渠道 B 拉取。

**渠道 B：内置库按时间范围拉取**

入口：后端接口文档 `http://localhost:8000/docs` → 展开 `POST /api/datasets/pull`

| 步骤 | 操作 |
| --- | --- |
| 1 | 点「Try it out」，在请求体填写：`target_dataset_id`（目标数据集 ID）、`start_time` / `end_time`（起止时间，ISO 格式，如 `2026-09-01T00:00:00`）、`quality`（「合格」只保留质量合格记录，或「全部」）。 |
| 2 | 点「Execute」执行，返回 `pulled`（拉取条数）。 |

拉取是复制关联：源记录只读不动，不会被删除或移动。

### 3.3 图片浏览检索（需求 6.3）

页面：`/annotate?dataset=数据集ID`

| 操作 | 步骤 |
| --- | --- |
| 翻上一张/下一张 | 点击图片下方「上一张」「下一张」按钮，或按键盘 ← / → 键。首张时「上一张」禁用，末张时「下一张」禁用。 |
| 进度条跳转 | 拖动「上一张/下一张」之间的进度条滑块到任意位置。 |
| 当前位置显示 | 图片下方左侧显示「n / m」（第 n 张 / 共 m 张），右侧显示当前文件名。 |
| 文件名搜索 | 在右上角搜索框输入文件名关键字，点「搜索」（或按回车）。命中结果列表替换当前浏览列表并定位到第 1 张；无匹配时显示「无匹配图片」。点「重置」清空搜索恢复完整列表。 |
| 查看结构化标签 | 右侧标注面板的标签树勾选状态即当前图片的舌/面/脉/声音四类标签（读取自该图同名 XML）；面板底部以标签形式汇总已选标签。 |

### 3.4 标注操作（需求 6.4）

页面：`/annotate?dataset=数据集ID`，右侧「标注面板」。

| 操作 | 步骤 |
| --- | --- |
| 打标签 | 1. 在标签树中点击目标子标签勾选；2. 同一类别内为单选，勾选新标签会自动取消该类其他标签；3. 四个类别各最多选 1 个，一张图可含 0 到 4 个标签。也可点击标签行文字切换勾选。 |
| 自动保存 | 勾选标签后系统自动保存，无需手动操作。面板底部保存状态依次显示「待自动保存…」（约 300ms 内）→「保存中…」→「已保存」；失败显示「保存失败」。翻页前未落盘的修改会立即发出，不丢失。 |
| 手动保存 | 点面板底部「保存」按钮（或按键盘 S 键），立即把当前选择写入 XML。 |
| 质量标记 | 点面板右上「质量：未标记」按钮（或按键盘 Q 键）切换为「合格」，按钮变绿；再按一次清除标记。「不合格」仅由导入的 XML 带入，页面不直接设置。 |
| 删除当前数据 | 1. 点面板底部红色「删除」按钮；2. 二次确认弹窗点「删除」。图片文件与标注 XML 一并删除，不可恢复；内置库源记录不受影响。 |

### 3.5 标注导出（需求 6.5）

入口：浏览器直接访问 `http://localhost:8000/api/datasets/{dataset_id}/export`（把 `{dataset_id}` 换成数据集 ID），触发 ZIP 下载。也可在后端接口文档 `http://localhost:8000/docs` 中展开 `GET /api/datasets/{dataset_id}/export` 执行。

导出包内含全部图片与同名标注 XML（含 quality 字段）；未标注记录同样导出；空数据集导出合法空 ZIP。导出包可再次经 3.2 节渠道 A 导入，往返一致。

### 3.6 数据集选择（训练用，需求 6.6）

页面：`/train`，训练配置卡片第一行。

| 操作 | 步骤 |
| --- | --- |
| 选主训练集 | 在「训练数据集」第一下拉框选择主训练集（必选，仅能选 1 个）。 |
| 叠加数据集 | 在第二个下拉框「追加数据集」多选额外数据集，与主训练集混合构成训练数据。已选为主训练集的数据集在该框中禁用。 |
| 标签体系校验 | 启动训练时后端自动校验主集与全部叠加集标签体系一致，不一致则拒绝启动并报错。 |

### 3.7 模型架构（需求 6.7）

页面：`/train`，「骨干网络」单选项。

- 选「ResNet18」或「ResNet50」使用预置骨干（预训练权重初始化）。
- 选「自定义上传」可上传 .py 模型文件；注意：**训练引擎当前仅支持 ResNet18/ResNet50**，自定义模型请在「批量推理」页（`/infer`）加载使用，训练页选择自定义时点「启动训练」会被拦截并提示。

模型输出 4 个并行分类头，分别对应舌/面/脉/声音，每头输出维度等于该类别子标签数。

### 3.8 GPU（需求 6.8）

页面：`/train`。

- 启动训练时后端自动检测可用 GPU 数量：0 块用 CPU，1 块单卡，多块自动 DataParallel 多卡并行。
- 「FP16 混合精度」开关：GPU 可用时开启加速训练；无 GPU 时自动降级为 FP32 训练。
- 训练启动后，下方「训练监控」卡片的任务信息行会显示实际使用的设备（`设备：cuda:0` 或 `设备：cpu`）与 `AMP/FP16` 标记。

### 3.9 参数可调（需求 6.9）

页面：`/train`，训练配置表单。

| 参数 | 控件 | 说明 |
| --- | --- | --- |
| 学习率 lr | 数字输入框 | 范围 0.0001 至 1，默认 0.001 |
| batch size | 数字输入框 | 范围 1 至 512，默认 16 |
| 训练轮数 epochs | 数字输入框 | 范围 1 至 1000，默认 10 |
| 优化器 | 下拉框 | SGD / Adam / AdamW，默认 Adam |
| Dropout | 数字输入框 | 范围 0 至 0.9，默认 0，作用于各分类头 |
| 损失函数 | 下拉框 | CrossEntropy（默认）/ FocalLoss，作用于 4 个分类头并求和 |

修改任一参数后点「启动训练」，训练按新值生效。

### 3.10 数据增强（需求 6.10）

页面：`/train`，「数据增强」复选框组。

勾选「随机水平翻转 / 随机旋转 / 颜色抖动 / 随机裁剪」中的任意组合，训练时按所选组合应用于训练数据。增强仅作用于训练数据，验证与推理数据不受影响。

### 3.11 断点续训（需求 6.11）

页面：`/train`，「断点续训」下拉框。

| 操作 | 步骤 |
| --- | --- |
| 从存档续训 | 1. 在下拉框选择要恢复的 checkpoint（列表来自模型目录）；2. 其余参数可用默认或修改；3. 点「启动训练」。 |
| 状态恢复 | 恢复模型参数、优化器状态、已训练轮数、最佳指标追踪，继续训练不从零开始。监控区任务信息行显示「续训自：<存档名>」。 |
| 存档校验 | 存档含模型结构信息与类别数，加载时自动校验；损坏或不匹配的存档给出明确错误。 |

### 3.12 训练监控（需求 6.12）

页面：`/train`，下方「训练监控」卡片。

| 操作 | 步骤 |
| --- | --- |
| 启动训练 | 填好 3.6 至 3.11 节各项配置后点「启动训练」。任务在后台执行，页面不阻塞。 |
| 查看实时指标 | 监控卡片顶部标签显示连接方式（「实时推送（WebSocket）」或「轮询兜底（每 2s）」）；任务信息行显示状态、`epoch x / y`、设备、FP16、续训来源。 |
| 查看曲线 | 「损失曲线」与「准确率曲线（训练/验证）」两张图随每个 epoch 结束自动追加数据点，无需手动刷新。 |
| 切换监控任务 | 右上角「选择监控任务」下拉框可切换查看历史任务。 |
| 停止训练 | 选中要停止的任务后点「停止训练」，训练在当前 batch/epoch 边界优雅退出。 |
| 刷新恢复 | 页面刷新后，曲线按后端已记录指标重建。 |

训练完成后系统提示「训练任务已完成，可前往评估可视化查看结果」，也可点「前往评估 →」按钮直接跳转（自动携带 job_id）。

### 3.13 评估可视化（需求 6.13）

页面：`/evaluate`。

| 操作 | 步骤 |
| --- | --- |
| 选择任务 | 在下拉框选择训练任务（含状态标签），或点「查询评估」按钮。 |
| 查询评估 | 选中任务后点「查询评估」按钮，加载该任务验证集的评估结果。 |
| 查看混淆矩阵 | 「混淆矩阵」区渲染舌/面/脉/声音 4 张热力图（行=真实标签，列=预测标签）；某类无验证样本时显示「xx：无验证样本」。 |
| 查看 ROC | 「ROC 曲线（one-vs-rest）」区渲染 4 组曲线并标注 AUC 值。 |
| 空结果提示 | 训练未完成显示「训练未完成，评估暂不可用」；无验证集显示「暂无评估结果」，页面不报错不白屏。 |
| 返回训练页 | 点「← 返回训练」按钮。 |

### 3.14 模型加载/保存（需求 6.14）

- **加载**：训练页「断点续训」下拉框与推理页/ONNX 页「选择模型」下拉框均列出模型目录（`MODEL_DIR`）中的权重文件（.pth/.pt），选中即加载。
- **保存**：训练过程自动保存产物到模型目录：
  - 最佳模型（best）：判据为 4 个分类头宏平均验证准确率的算术均值最大，文件名形如 `<job_id>_best.pth`；
  - 最新存档（latest）：每轮更新，文件名形如 `<job_id>_latest.pth`。

### 3.15 推理数据集选择（需求 6.15）

页面：`/infer`。

| 操作 | 步骤 |
| --- | --- |
| 选模型 | 右上角「选择模型」下拉框选择模型权重。模型目录无 .pth/.pt 时页面顶部显示警告「模型目录中没有可用的模型权重」，提示先训练或放入 checkpoint 后点「刷新」。 |
| 选数据集 | 「选择数据集」下拉框选择推理目标数据集。无数据集时同样有警告提示。 |

### 3.16 批量预测（需求 6.16）

页面：`/infer`。

选好模型与数据集后点「批量预测」按钮，系统对数据集内全部图片执行推理。完成后弹出「批量预测完成：共 N 张图片」；返回结果数等于数据集图片数。模型结构从所选权重自动重建；无法识别结构的第三方权重给出明确错误。

### 3.17 结果表格（需求 6.17）

页面：`/infer`，批量预测完成后自动展示。

表格列：文件名 + 舌/面/脉/声音 4 列。每列显示预测子标签（标签形式）与概率（百分比，如 `87.50%`）。行数等于推理图片总数；无预测结果的类别显示空白占位符。数据集无图片时提示「该数据集没有图片，无预测结果」。

### 3.18 预标注 XML 生成（需求 6.18）

页面：`/infer`。

选好模型与数据集后点「生成预标注 XML」按钮。生成的 XML 与人工标注使用同一 schema，可被标注页直接读取编辑；`confidence` 写入模型预测概率（0 到 1）。完成后弹出「预标注 XML 生成完成：共生成 N 个」。预标注只生成到独立输出目录，不覆盖已有人工标注。

### 3.19 PyTorch→ONNX 一键转换（需求 6.19）

页面：`/onnx`。

1. 在「选择模型」下拉框选择要转换的模型（列表来自模型目录；无模型时页面顶部警告并提示先训练或放入 checkpoint 后点「刷新」）。
2. 点「一键转换并对比」按钮，系统导出 .onnx 文件并提示文件名。
3. ResNet18/50 产物保证可转换；自定义模型转换失败时明确提示不支持，不会崩溃。产物可由 ONNX Runtime 正常加载。

### 3.20 精度对比（需求 6.20）

页面：`/onnx`。转换完成后系统自动执行对比，无需额外操作。

- 对比表按分类头逐行展示：分类头、最大绝对误差（max_abs_diff）、阈值（1e-3）、结果（PASS/FAIL）。
- 判定：每头最大绝对误差 < 1e-3 判 PASS，否则 FAIL。
- 4 头全部 PASS 时顶部显示绿色成功提示「转换完成，精度对比通过」；存在 FAIL 时显示红色错误提示并建议检查权重或重新训练。

### 3.21 ONNX 模型一键下载（需求 6.21）

页面：`/onnx`。

精度对比通过（overall PASS）后，顶部出现绿色「下载 .onnx」按钮，点击即触发浏览器下载该 .onnx 文件。未通过对比时按钮禁用。

## 4. 标注页键盘快捷键

快捷键仅在标注页 `/annotate` 有效，且需要：URL 携带有效 `dataset` 参数、图片列表非空、焦点不在文本输入框（搜索框）内。按住 Ctrl/Meta/Alt 时快捷键不触发。

| 按键 | 功能 | 对应代码行为 |
| --- | --- | --- |
| `←` / `→` | 上一张 / 下一张图片 | `prev()` / `next()` |
| `1` / `2` / `3` / `4` | 定位到第 1/2/3/4 个类别（舌/面/脉/声音）分类头，滚动标签树到该类别 | `focusCategory(index)` |
| `S`（大小写均可） | 立即手动保存当前标注 | `manualSave()` |
| `Q`（大小写均可） | 切换「质量合格」标记（再按一次清除） | `toggleQuality()` |

说明：数字键只负责定位类别标题，勾选子标签仍需鼠标点击标签树；标签勾选后自动保存（见 3.4 节），S 键为手动兜底。

## 5. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 标注页显示「请从数据集管理页进入标注页」 | URL 缺少 `?dataset=数据集ID` 参数，按 2 节格式补全。 |
| 新建数据集报「名称已存在」 | 数据集名唯一，换一个名称。 |
| 推理/ONNX 页没有可选模型 | 模型目录为空。先在 `/train` 页完成一次训练，或手动把 checkpoint 放入模型目录后点「刷新」。 |
| 评估页显示「暂无评估结果」 | 训练未完成、或该任务无验证集，属于正常提示。 |
| 启动训练报标签体系不一致 | 主训练集与某个叠加数据集的标签体系不同，去掉该叠加集或改用一致的数据集。 |
| 训练监控曲线不更新 | 查看卡片顶部连接标签；WebSocket 断开时自动切换为每 2s 轮询并尝试重连，稍候即可。 |
| 自定义模型点训练无反应 | 训练引擎仅支持 ResNet18/ResNet50，自定义模型请在 `/infer` 页使用。 |
| ONNX「下载 .onnx」按钮是灰的 | 精度对比未通过（存在 FAIL 头），按 3.20 节提示检查权重。 |
